# Zomato Clone🍕

A frontend clone of the Zomato website created using **HTML, CSS, and JavaScript**.

This project is a food delivery website interface inspired by Zomato, containing multiple webpages, restaurant sections, login/signup pages, and custom styling.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- AI tools for guidance, debugging, and improving design ideas during development

## Features

- Zomato-inspired homepage
- Restaurant listing section
- Add restaurant page
- Investor relation page
- Login and signup pages
- Food and background images
- Multiple linked webpages
- Custom CSS styling
- JavaScript-based interactions
- Organized project structure
